KOZA NIGHT WALK

店舗リスト

実在が公開情報で確認できた店舗のみ掲載しています。

    実データ：地形・建物・道路・店舗位置・写真・営業時間（Google）
    演出：夜景フィルター、カメラワーク、ネオン風 UI

    Google Maps Platform の API キー

    3D 地図・ストリートビュー・店舗情報の表示に必要です。キーはこのブラウザ内（localStorage）にのみ保存されます。

    必要な API
    • Map Tiles API（Photorealistic 3D Tiles）
    • Maps JavaScript API（ストリートビュー・地図）
    • Places API (New)（店舗の位置・写真・営業時間）
    • Directions API（任意：道順の線）

    キーには HTTP リファラー制限を設定してください。
