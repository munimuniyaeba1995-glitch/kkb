# KOZA NIGHT WALK

沖縄市コザ「サンシティ通り（サンシティ商店街）」をバーチャルで飲み歩く Web コンテンツの試作版です。
**API キー・会員登録・課金は一切不要**。HTML / CSS / JavaScript だけの静的サイトです。

## 使い方

### スマホで開く

- **GitHub Pages（おすすめ）**: リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `claude/cool-pasteur-307ph6`・`/ (root)` にして Save。1〜2 分後に https://munimuniyaeba1995-glitch.github.io/kkb/ で開けます。
- **すぐ試す（設定不要）**: 外部サービス githack 経由で、GitHub 上のファイルをそのまま表示できます。URL はコミットごとに変わります。

### ローカルで開く

`index.html` を Web サーバーに置いて開きます（ファイルを直接ダブルクリックしても動きません）。ローカルなら:

```
python3 -m http.server
```

## 使っているもの（すべてキー不要）

| 役割 | 使っているもの | 備考 |
| --- | --- | --- |
| 地図の描画 | MapLibre GL JS 4.7.1（`vendor/` に同梱、BSD-3） | CDN に依存しない |
| 地図タイル・3D 建物 | OpenFreeMap（OpenMapTiles 形式のベクタータイル） | 取得できなければ OSM 標準タイルへ |
| 予備の地図 | OpenStreetMap 標準タイル | 少量アクセス向け。3D 建物なし |
| 道路・店舗データ | OpenStreetMap（Overpass API） | 結果を 24 時間ブラウザに保存し、公共サーバーへの負荷を抑える |

著作権表示: 地図右下と画面下部に「© OpenStreetMap contributors」（ODbL）と OpenFreeMap / OpenMapTiles を常時表示します。

## 機能

- 初期表示は沖縄市コザ。サンシティ通りを中心に表示
- **フリー**: ドラッグ／ピンチ／2 本指で回転・傾き。マーカーをタップで店舗詳細。「通りを歩く」で歩行ビューに入り、「進む／戻る」を押している間（または ↑↓ キー）道路に沿って移動。現在地と訪問済み店舗を表示
- **自動ツアー**: スタート → コザ上空から降下 → 歩行ビュー → 道路に沿って店へ → 店の方向を向いて停止・詳細表示 → 「次へ」。一時停止・再開・終了
- **3D 建物**: 「3D」ボタンで表示切り替え（ベクタータイル取得時のみ）
- **夜景**: 色調フィルターとネオン風 UI（演出。「夜景」ボタンで OFF）

## データの方針

- 店舗の位置・名称・種別・営業時間・電話などは、実行時に OpenStreetMap から取得したものだけを表示します。未登録の項目は「OSM に登録なし」と表示し、架空のデータで補いません。写真も OSM に登録がある場合だけ表示します。
- 通りの線は、OSM で名前に「サンシティ」を含む道路をつないで作ります。
  - 同名の道路が無く、同名の施設（商店街など）だけある場合は、その周辺 120 m の飲食店を表示し、線は「店舗間を結ぶ概略」と明示します。
  - どちらも無い場合は、店舗マーカーを出さずその旨を表示します。
- `js/data.js` の `notes` は、公開記事で裏が取れた店の補足（特徴と出典）です。OSM の店名と一致すれば詳細に添え、OSM に無ければ「位置未確認」としてリストにだけ出します。

## 取得できないとき

| 状況 | 表示 |
| --- | --- |
| ベクタータイルが取れない | OSM 標準タイルの通常地図（3D 建物なし） |
| タイルがどれも取れない | 無地の背景に道路の線と店舗だけ |
| 店舗データが取れない | 地図のみ。リストには公開情報で確認できた店を位置なしで表示 |
| 地図ライブラリが動かない | デモ画面（位置関係は表さないと明示）。ツアーは店舗カードを順に表示 |

## 構成（地図部分は差し替え可能）

```
index.html
css/style.css
js/data.js            設定（中心座標、Overpass、タイル）と店舗の補足
js/geo.js             距離・方位・線上の位置の計算
js/osm.js             Overpass から通りと店舗を取得
js/map-maplibre.js    地図アダプター（MapLibre 版）
js/app.js             UI・歩行・自動ツアー（地図ライブラリを直接触らない）
vendor/               MapLibre GL JS
```

`app.js` は `window.KNW_createMap()` が返すアダプターのメソッド（`flyTo / setCamera / getCamera / stop / setStreet / setStores / setCurrent / set3D`）だけを使います。将来 Google Earth や CesiumJS に替える場合は、同じメソッドを持つアダプターを書いて差し替えます（仕様は `js/map-maplibre.js` 冒頭）。以前の Google 版はコミット履歴にあります。
