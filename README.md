# KOZA NIGHT WALK

沖縄市コザ「サンシティ通り（サンシティ商店街）」を、Google の 3D 地図とストリートビューでバーチャル飲み歩きする Web コンテンツです。

## 使い方

1. 静的ファイルなので、任意の Web サーバー（GitHub Pages など）に置いて `index.html` を開きます。ローカルなら `python3 -m http.server` で可。
2. 初回に Google Maps Platform の API キーを入力します（ブラウザの localStorage にのみ保存。リポジトリには入れません）。

必要な API（Google Cloud で有効化）:

| API | 用途 |
| --- | --- |
| Map Tiles API | Photorealistic 3D Tiles（上空〜降下の 3D 表示） |
| Maps JavaScript API | ストリートビュー、ミニマップ、3D が使えない時の通常地図 |
| Places API (New) | 店舗の位置・写真・営業時間・Google マップへのリンク |
| Directions API（任意） | 実際の道路に沿った徒歩ルート。無い場合は店舗間を結ぶ概略線（画面に明示） |

キーには HTTP リファラー制限をかけてください。

## モード

- **フリー**: ドラッグ／スワイプ／ピンチで自由に視点移動。マーカーをタップで店舗情報。「通りを歩く」でストリートビューに降り、矢印で道なりに移動。現在地と訪問済み店舗を表示。
- **自動飲み歩き**: スタート → 沖縄市上空からドローン風に降下 → 歩行者目線に切替 → 道に沿って店舗へ → 店舗前で停止して紹介 → 「次へ」。一時停止・再開・終了が可能。

## 実データと演出の区別

| 実データ（Google） | 演出 |
| --- | --- |
| 地形・建物・道路（3D Tiles / Street View） | カメラワーク（降下の軌道・速度） |
| 店舗の位置・写真・営業時間・営業状況（Places） | 夜景フィルター（実写に色調補正。「夜景」ボタンで OFF） |
| 徒歩ルート（Directions、Street View の接続） | ネオン風の UI |

実写は昼間撮影の場合があります。夜の人通りやネオンを CG で描き足すことはしていません（実在しないものを作らないため）。

## 店舗データの方針

- `js/data.js` には、公開情報で裏が取れた店名・住所・特徴と出典 URL だけを書きます。
- 緯度経度・営業時間・写真は書かず、実行時に Google Places から取得します。取得できない項目は「確認できませんでした」と表示し、推測で補いません。
- Places の結果は「店名が一致」かつ「沖縄市中心部にある」場合だけ採用します。採用できない店は地図に出しません。
- 「周辺の店を追加」は、道順から 15 m 以内で営業中登録の飲食店を Google マップから取得します（自動取得と明示）。

現在の掲載店（2026-11 時点の公開情報で確認）: ロロイチ／鉄板料理と和食の店 なかた／牡蠣専門居酒屋 カキラバ。

## 3D が使えない場合

3D Tiles の読み込みに失敗した、または 15 秒以内にタイルが届かない場合は、自動で通常の Google マップ（航空写真）に切り替わります。ストリートビューが無い地点では地上に切り替えず、その旨を表示します。

## 検証状況

- モック（テスト用の偽 Google API と極小 3D タイル）を使ったブラウザ自動テストで、3D 降下→歩行→店舗紹介→次へ→完了、一時停止／再開／終了、2D フォールバック、キー未設定の各経路が動くことを確認済み。
- **実際の Google API キーでの動作は未確認**です（開発環境にキーが無いため）。サンシティ通りのアーケード内にストリートビューがあるか、各店が Places で解決できるかは、キーを入れた初回起動で確認してください。
