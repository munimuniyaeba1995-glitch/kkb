# ASHEN CROWN（灰の王冠）

オリジナルのダークファンタジー3DアクションRPG（試作版 v0.3）。**スマートフォン（Android）優先・PC対応**。
無料のゲームエンジン **Godot 4.3** と GDScript で作っています。素材ファイルは使わず、形状・UIはすべてコードで生成しています。

## 0. スマホで遊ぶ（Android）

### A. 配布されたAPKを入れる（いちばん簡単）
1. `AshenCrown.apk` をスマホにコピー（USB・Googleドライブなど）。
2. スマホでファイルを開く →「提供元不明のアプリ」のインストールを許可 → インストール。
3. 起動すると横画面で始まります。対応: **Android 7.0 以上・64bit端末（arm64）**。

### B. 自分のPCでAPKを作る
1. **JDK 17**（無料: Eclipse Temurin https://adoptium.net/）をインストール。
2. **Android SDK**: Android Studio（無料）を入れて SDK Manager から
   「Android SDK Platform-Tools」「Android SDK Build-Tools 34」「Android SDK Command-line Tools」を入れる。
3. Godot の「エディタ → エディタ設定 → エクスポート → Android」で
   *Java SDK Path*（例 `C:\Program Files\Eclipse Adoptium\jdk-17...`）と
   *Android SDK Path*（例 `C:\Users\<名前>\AppData\Local\Android\Sdk`）を設定。
   デバッグ用キーストアは Godot が自動で用意します。
4. 「エディタ → エクスポートテンプレートの管理 → ダウンロード」（初回のみ・約1GB）。
5. 「プロジェクト → エクスポート → Android → プロジェクトのエクスポート」で `build/android/AshenCrown.apk` ができる。
   スマホを USB デバッグ有効でつなげば、エディタ右上の Android アイコンでワンクリック実行もできます。

### iPhone で遊ぶ（Web版・Safari）
1. 共有されたリンクを **Safari** で開く（iOS 16.4 以降）。
2. 読み込み（約9MB）が終わったら、**iPhone を横向き**にする。
3. 「はじめから」をタップ。操作はAndroid版と同じタッチ操作です。
- ホーム画面に追加すると全画面に近い表示で遊べます（共有ボタン →「ホーム画面に追加」）。
- Web版は音声・セーブ機能の追加後も同じリンクで更新されます。

アプリ版（App Store形式）の iOS ビルドには **Mac と Xcode（無料）が必須**です（Windowsでは作れません）。
自分の iPhone に入れるだけなら無料の Apple ID で可能（7日ごとに入れ直し）、App Store 配信には Apple Developer Program（年額 $99）が必要です。

### Web版を自分で書き出す
Godot の「プロジェクト → エクスポート → Web」→ `build/web/`。
1ファイル15MBまでの置き場所（Claudeのアーティファクト）向けには `tools/web_artifact/build.sh` で `build/web_artifact/` を作る。
ブラウザで開くにはWebサーバーが必要です（例: `python -m http.server --directory build/web` → http://localhost:8000）。

## 1. PCで開いて遊ぶ・開発する（Windows）

1. **Godot 4.3（Standard版・無料）をダウンロード**
   https://godotengine.org/download/archive/4.3-stable/ → 「Windows 64-bit」
   ZIPを展開するだけで使えます（インストール不要）。`C:\Godot\` などに置いてください。
   ※ 4.4 以降でも開けますが、動作確認は 4.3 で行っています。
2. **このプロジェクトを手元に置く**
   GitHubのこのリポジトリで「Code → Download ZIP」→ 展開（例: `C:\Games\ashen-crown\`）。
   Git を使う場合は `git clone` でもOK。
3. **Godotで開く**
   `Godot_v4.3-stable_win64.exe` を起動 → 「インポート」→ 展開したフォルダの `project.godot` を選択 →「インポートして編集」。
   初回はインポート処理に数十秒かかります。
4. **遊ぶ**
   エディタ右上の ▶（または **F5**）でタイトル画面から起動します。

## 2. 操作方法

### スマートフォン（タッチ）
| 操作 | 方法 |
|---|---|
| 移動 | 画面左側をなぞる（触れた場所に仮想スティックが出る） |
| カメラ | 画面右側の空いている所をなぞる |
| 攻撃 / 強攻撃 | 剣のボタン「攻撃」（連打で3連撃）/ 大剣のボタン「強攻撃」 |
| 回避 / ダッシュ | 矢印のボタン「回避」を短く押す / 長押し＋移動 |
| ガード | 盾のボタン「ガード」を押している間 |
| ロックオン | 照準のボタン「ロック」 |
| 回復・ジャンプ・調べる | 小瓶「回復」・↑「跳躍」・手「調べる」（篝火や宝箱の近くでだけ表示） |
| ポーズ・設定 | 右上の「II」（画質 低/中/高、タッチ操作オン/オフ、性能表示） |

PCでタッチ操作を試す: ポーズ → 「タッチ操作: ON」（マウスが指の代わりになる）。

### PC（キーボード・マウス / ゲームパッド）

| 操作 | キーボード/マウス | ゲームパッド |
|---|---|---|
| 移動 | WASD | 左スティック |
| カメラ | マウス（矢印キーでも可） | 右スティック |
| ダッシュ | Space 長押し | B 長押し |
| 回避（出始めが無敵） | Space 短押し | B |
| ジャンプ | F | A |
| 弱攻撃（3連撃） | 左クリック | RB |
| 強攻撃 | Shift+左クリック または C | RT |
| ガード | 右クリック長押し | LB |
| ロックオン | Q / ホイールクリック | 右スティック押し込み |
| 回復薬 | R | X |
| 調べる・休息 | E | Y |
| ポーズ / 操作説明 | Esc / F1 | Start / Back |

## 3. 試作版の遊び方（テスト手順）

1. 開始地点の左にある篝火で **E** → 休息（HP・回復薬の回復、復活地点の更新、敵の再配置）。
2. 前庭の「灰憑きの兵」を倒す。武器が**赤く光ったら攻撃の予備動作**。光り終わる直前に回避すると無傷で抜けられる。
3. 前庭の**西の壁**に一か所だけ色の違う壁がある → 攻撃すると隠し部屋。右奥の角には宝箱（回復薬+1）。
4. 回廊を抜けると処刑場跡に強敵「黒鉄の処刑人」。3連撃・突進突き・溜め攻撃（ディレイ）を使う。
5. 奥の篝火で休息してから霧の門へ。ボス「灰冠の守護者 ヴォルグレイン」と戦う。HP半分で第2形態。
6. 倒すと「守護者を討ち果たした」と表示されて試作版クリア。

死亡すると所持していた残灰（経験値）をその場に落とします。触れれば回収できますが、**回収前にもう一度死ぬと前回の分は消滅**します。

## 4. 自動テスト（開発者向け）

戦闘・ガード・回避の無敵・ボス戦・死亡と回収・休息・隠し壁・**タッチ操作（スティック・ボタン・カメラ・タッチだけでボス撃破）**・画質設定・キャラクターの体型と歩行・タイトル画面を、実際の物理と当たり判定で検証します（30項目）。

- Windows: `set GODOT=C:\Godot\Godot_v4.3-stable_win64_console.exe` → `tools\run_tests.bat`
- Linux/macOS: `GODOT=/path/to/godot tools/run_tests.sh`

最後に `結果: 30 / 30 PASS` と出れば成功です。
